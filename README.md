# Автопостер · Любовь · AI-системы (@lubovy_pr)

Скрипт сам публикует контент по таблице `plan.csv`: посты и сторис в Телеграм-канал, а также карусели, рилсы и сторис в Инстаграм. Запускается на GitHub каждый день в 19:00 по Москве (и вручную — в любой момент), компьютер для этого включать не нужно.

```
plan.csv       ← план (пишем мы / Claude): что, когда, куда, текст, файлы
media/         ← картинки и видео, по папкам-дням: media/2026-09-28/...
status.csv     ← журнал (пишет только скрипт): что вышло, когда, ссылка или ошибка
publisher/     ← скрипты
```

## Оформление слайдов

Ник, имя и подпись под аватаркой — в `content/brand.py`. Фото для обложек — в `content/photos/`, аватарка — `content/photos/avatar.jpg` (квадрат).
Картинки собирает сценарий **Actions → Сборка картинок** (поле — дата из имени файлов `content/carousels_ДАТА.py`, `tg_ДАТА.py`, `stories_ДАТА.py`), готовое кладёт в `media/ДАТА/`.

## Как устроена таблица plan.csv

Разделитель «;», кодировка UTF-8. Файл открывается в Excel и Numbers.

| колонка | что писать |
|---|---|
| id | уникальное имя строки латиницей, например `0928-ig-car` |
| дата | `2026-09-28` |
| время | `10:30`, по Москве |
| площадка | `telegram` или `instagram` |
| формат | `пост` · `сторис` · `карусель` · `рилс` |
| статус | `черновик`: не публикуется · `готово`: выйдет в срок · `пропустить` · `повторить`: повторная попытка после ошибки |
| текст | текст поста или подпись. Для Телеграма можно `**жирный**`, `__курсив__`, `[ссылка](https://...)` |
| медиа | пути к файлам через `\|`, например `media/2026-09-28/car_1.jpg\|media/2026-09-28/car_2.jpg` |
| комментарий | для себя, скрипт его не читает |

Правила:
- Одна строка — одна публикация на одной площадке. Если одна и та же сторис идёт в ТГ и в ИГ, заводим две строки.
- **Опубликованное никогда не публикуется повторно.**
- Если публикация опоздала больше чем на 6 часов (например, GitHub лежал), она пропускается, чтобы не выйти невпопад.
- При ошибке приходит сообщение в Телеграм, если задан `TG_ADMIN_CHAT_ID`. Чтобы попробовать ещё раз, поставьте в строке статус `повторить`.

Размеры: сторис 1080×1920; карусель 1080×1350, от 2 до 10 слайдов, только JPG; рилс в формате MP4 9:16. Обложку рилса (JPG) можно указать вторым файлом.

## Подключение: один раз, по шагам

### Шаг 1. GitHub
1. Зарегистрируйтесь на github.com.
2. Создайте репозиторий: **New repository** → имя `avtoposter-lubovy` → **Public** → Create.
   > Репозиторий должен быть публичным: Инстаграм забирает картинки по открытой ссылке. Публичными становятся только контент и код, а все ключи лежат в зашифрованных Secrets, их никто не видит.
3. Загрузите в репозиторий все файлы из этой папки: **Add file → Upload files**, перетащить всё, включая скрытую папку `.github`.
   Со следующей недели файлы будет загружать Claude.

### Шаг 2. Телеграм-бот (посты)
1. В Телеграме откройте @BotFather → `/newbot` → придумайте имя → скопируйте **токен**.
2. Канал → Управление → Администраторы → добавьте бота с правом «Публикация сообщений».
3. Узнайте свой числовой id для уведомлений об ошибках: напишите боту @userinfobot.

### Шаг 3. Сторис в Телеграм-канале (по желанию)
Боты не умеют публиковать сторис в каналы, поэтому сторис выходят от имени администратора канала.
1. Зайдите на my.telegram.org → API development tools → создайте приложение. Понадобятся `api_id` и `api_hash`.
2. На компьютере в **обычном Терминале** выполните:
   ```
   pip3 install telethon
   python3 publisher/login_telegram.py
   ```
   Введите api_id, api_hash, телефон и код из Телеграма. Скрипт выдаст длинную строку — это `TG_SESSION`.
3. У канала должен быть уровень бустов: уровень 1 минимум, чтобы сторис были доступны, и примерно N сторис в день на уровне N. Бусты дают подписчики с Premium.

### Шаг 4. Инстаграм
1. Переключите аккаунт на профессиональный: Настройки → Тип аккаунта → «Автор» или «Бизнес».
2. developers.facebook.com → My Apps → **Create app** → сценарий «Manage messaging & content on Instagram» (Instagram API).
3. В приложении: Instagram → API setup with Instagram login → **Add account**. Войдите в аккаунт @lubovy_pr и нажмите **Generate token**. Скопируйте токен — это `IG_ACCESS_TOKEN`.
   Приложение может оставаться в режиме разработки, для своего аккаунта проверка Meta не нужна.
4. `IG_USER_ID` подскажет проверка подключения на шаге 6.

### Шаг 5. Ключи в GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Добавьте:

| имя | значение |
|---|---|
| `TG_BOT_TOKEN` | токен бота |
| `TG_CHANNEL` | `@имя_канала` (или `-100…` для закрытого канала) |
| `TG_ADMIN_CHAT_ID` | ваш числовой id (сюда будут приходить ошибки) |
| `TG_API_ID`, `TG_API_HASH`, `TG_SESSION` | для сторис в ТГ |
| `IG_ACCESS_TOKEN`, `IG_USER_ID` | для Инстаграма |
| `GH_PAT` | для автопродления токена Инстаграма (см. ниже) |

**GH_PAT:** github.com → Settings → Developer settings → Fine-grained tokens → Generate. Доступ только к репозиторию `avtoposter-lubovy`, права Secrets: *Read and write*. Токен Инстаграма живёт 60 дней, и отдельный сценарий продлевает его сам 1-го и 15-го числа.

### Шаг 6. Проверка и тест на одном посте
1. **Actions → Автопостер → Run workflow → режим `check-setup`**. Покажет, что подключено, а что нет, ничего не публикуя.
2. **Run workflow → режим `publish`, id = `test-tg-post`**. Выйдет один тестовый пост в канал. Ссылка на него появится в `status.csv`.
3. Затем по очереди: `test-ig-carousel`, `test-tg-story`, `test-ig-story`. Тестовые публикации потом удалите вручную.
4. После теста расписание работает само: в 19:00 выходит всё, у чего статус `готово` и наступило время.

## Команды для проверки на компьютере
```
pip3 install -r requirements.txt
python3 publisher/publish.py --check     # проверить план и файлы, ничего не публикуя
```

## Что важно знать
- GitHub запускает расписание с задержкой 5–30 минут: запуск «19:00» фактически бывает в 19:05–19:30.
- Если в репозитории 60 дней не было изменений, GitHub выключает расписание. Нам это не грозит: журнал обновляется при каждой публикации.
- Инстаграм через API не добавляет в сторис музыку, стикеры и ссылки: всё должно быть на самой картинке.
- Лимит Инстаграма — 100 публикаций в сутки.
